# v5: rows of another study and consents without a partition, dropped with a warning

Run with `--foreign-study-rows=drop --unmatched-consent-rows=drop --max-reject-fraction=0.1` it succeeds (exit 0 with warnings) and writes only the four rows of `expected-partitions.csv`: the data rows whose first node is another study than the partition's (five, in both partitions, as the generator that selects rows by participant would leave them) and the three global `_consents` rows naming `phs000000.c0` and `phs999999.c0`, which have no partition, are counted as dropped, never written and never rejected, while the one row with an embedded line break is still rejected (the fraction counts it alone). With the default parameters the same input is refused with exit 3 (`REJECT_FRACTION_EXCEEDED`), `STUDY_PARTITION_MISMATCH=5` and `CONSENT_NOT_IN_MANIFEST=3`. All data is synthetic.
